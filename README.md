# Food Review Analyzer

An NLP-based application that analyzes food and restaurant reviews using Natural Language Processing and Machine Learning.

## Features

* Food review sentiment analysis
* Positive, negative and neutral classification
* Sentiment confidence score
* Rating prediction
* Aspect-based sentiment analysis
* Review history
* Review analytics
* Flutter mobile application
* FastAPI backend

## Technology Stack

* Python
* Pandas
* NumPy
* NLTK
* spaCy
* Scikit-learn
* FastAPI
* SQLite
* Flutter
* Dart
* Git and GitHub

## Project Workflow

Raw Dataset
→ Data Understanding
→ Data Cleaning
→ NLP Preprocessing
→ Exploratory Data Analysis
→ Feature Extraction
→ Sentiment Classification
→ Aspect-Based Sentiment Analysis
→ FastAPI Backend
→ Flutter Mobile Application
→ Testing and Deployment
